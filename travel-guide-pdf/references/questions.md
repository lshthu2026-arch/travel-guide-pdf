# 提问清单与推荐默认

开跑前用 request_user_input（或直接提问）一次问清以下各项；用户没答的用“推荐默认”，并在最终交付说明里列出采用的假设。每题给 2–4 个互斥选项，推荐项放第一并标注（推荐）。

## 1. 目的地与天数
- 自由文本：城市 + 几天。没有城市就没法往下做；天数默认 2 天。

## 2. 出行日期 / 窗口（重要，影响当季信息）
- 有具体日期（请填写，如 9/19–9/20）→ 按周末/工作日、当日活动、是否假期安排，查实时开放与客流
- 近期窗口（如本月内）→ 按当季天气、展览演出、假期预警编排（推荐）
- 未定 → 通用常青版，附四季与节假日提示

## 3. 人数与构成
- 情侣 / 两人（推荐默认）
- 朋友多人
- 亲子（含娃：节奏放缓、选亲子友好）
- 带长辈（少爬楼、正餐早、可替换观光）

## 4. 预算档位 + 酒店档位
预算：经济（人均每天 ¥200–400）/ 舒适中档（¥500–800，推荐默认）/ 轻奢（¥1000+）
酒店档位：快捷 / 亚朵层级（中端四星，推荐默认）/ 高端；城市名称可直接问“亚朵还是同档次/更高/更低”

## 5. 主题偏好
- 经典全景（首次必打卡，推荐默认）
- 文艺小众（街区漫步、美术馆、博物馆）
- 亲子乐园（主题乐园 + 亲子景点）
- 美食专项（必吃店为主、每餐主选 + 备选）

## 6. 输出细节
- 语言：中文（推荐默认）或双语
- 页面风格：地点大标题卡片 + 左右交替配图 + 每页右侧路线竖线/圆圈/交通标注（推荐默认）；或极简单栏；或奢华手册
- 是否要行程地图总览（高德瓦片底图 + 双色箭头）：默认要
- 图片：是否允许全册不重复 + 菜品/景点多图拼一框（推荐）；找不到实拍是否允许 AI 兜底并标注

## 7. 交付方式
- 保存到当前项目 output/pdf/ 下（推荐默认），PDF 文件名（默认如 city_2day_guide.pdf）
- 是否同时复制到桌面（默认询问一次后执行）

## 8. 联网与图片来源
- 是否允许联网调研携程/Trip.com、小红书等（默认允许；直连被反爬时用搜索引擎摘要 + 官方/聚合源并如实标注）
- 图片来源：Wikimedia/Openverse/官网高清实拍为主（默认）；个人自用不商用，来源尽力标注

## 交付说明模板
在最终回复里列出：目的地/天数、出行窗口假设、人数与预算、住宿档位、主题、输出路径，并提醒票价与营业信息以官网当日为准。
